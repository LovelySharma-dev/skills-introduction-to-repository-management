# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately to the project maintainers. Do not publish sensitive details or exploit instructions in public issues.

## Security Update Process

1. Monitor GitHub security alerts and dependency vulnerability notifications.
2. Review the affected dependency and assess the severity of the vulnerability.
3. Create a security-update branch or review the automated Dependabot pull request.
4. Update the vulnerable dependency to a safe version.
5. Run tests to verify that the application continues to work correctly.
6. Review and merge the fix after the required checks pass.
7. Confirm that the alert is resolved and document any necessary follow-up.

## Responsibilities

Project maintainers are responsible for reviewing security alerts, prioritizing critical vulnerabilities, and ensuring that fixes are tested before release.
