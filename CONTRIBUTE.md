# Contributing to Mergington High School

Thank you for helping improve our extracurricular activities website!

## How to Contribute

1. Check existing issues and project discussions before starting work.
2. Create a new branch for each feature or bug fix.
3. Make small, focused changes that are easy to review.
4. Write clear commit messages describing your changes.
5. Test your changes before submitting them.

## Pull Request Procedure

1. Push your branch to GitHub.
2. Open a pull request against the main branch.
3. Describe what you changed and why.
4. Link any related issues.
5. Wait for review and address requested changes before merging.

## Code Quality

- Follow the existing project structure and coding style.
- Keep code readable and maintainable.
- Avoid committing passwords, API keys, or other secrets.
- Update documentation when necessary.

## Communication

- Be respectful and constructive in discussions.
- Ask questions when instructions are unclear.
- Report bugs with clear reproduction steps.
- Follow the project's Code of Conduct.

Thank you for helping make our school website better!
